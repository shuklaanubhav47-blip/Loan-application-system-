Interactive Financial Education Module Builder

Project Overview

An interactive financial education and loan application frontend project developed using HTML5, CSS3, and JavaScript.

The project demonstrates multi-step form development, financial calculators, interactive learning components, responsive previews, content management, and client-side validation.

It includes a sample eight-step loan application form and several financial education tools designed to help users understand common financial concepts.

Features

1. Multi-Step Loan Application

- Responsive eight-step loan application form.
- Personal, address, identity, employment, loan, and bank details.
- Next and Back navigation.
- Progress indicator.
- Required-field validation.
- Email and mobile number validation.
- Document availability checklist.
- Application review before submission.
- Demo application reference and success confirmation.

2. Financial Calculators

- EMI Calculator for estimating loan instalments.
- SIP Calculator for estimating investment growth.
- Compound Interest Calculator for estimating future value and interest.

Calculator results are estimates and do not guarantee actual financial outcomes.

3. Interactive Financial Education

- Animated savings explainer.
- Financial learning progress tracker.
- Achievement badges.
- Responsive module preview.
- Module quality checker.

4. Content Management

- Multiple educational content block types.
- Content block editing and deletion.
- Drag-and-drop content organization.
- Undo and redo functionality.
- JSON export and import.

The availability and behavior of individual features depend on the current implementation in "index.html".

Technologies Used

- HTML5 — Page structure.
- CSS3 — Styling and responsive layouts.
- JavaScript — Form validation, calculators, and interactivity.
- Local Storage — Saving supported data in the browser.

Note: This version is implemented using HTML, CSS, and JavaScript. Framework and library requirements such as React, Zustand, Slate.js/TipTap, Framer Motion, and dnd-kit should be considered unimplemented unless they are added and verified separately.

How to Run

1. Open the repository and download "index.html".
2. Open the file in Google Chrome or another modern browser.
3. Use fictional information when testing the loan application.
4. Test the financial calculators with sample values.
5. Try the content management and preview features.
6. Test JSON export and import using sample content.

No additional software installation is required to run the basic frontend prototype.

Important Disclaimer

This project is for educational and demonstration purposes only.

It does not process real loan applications, verify identities, connect to banking systems, or submit applications to a server.

Do not enter real Aadhaar numbers, PAN numbers, bank account details, passwords, OTPs, or other sensitive personal information.

Financial calculator results are illustrative estimates, not financial advice.
